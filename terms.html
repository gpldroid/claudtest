الخدمة

يوفر Web2APK أدوات لإنشاء مشاريع Android تعتمد على WebView وبناء APK/AAB عبر GitHub Actions. الخدمة مجانية ضمن الحدود المعلنة داخل التطبيق.

مسؤولية المستخدم

يجب أن تملك أو تملك الإذن لاستخدام الموقع والمواد التي تحولها إلى تطبيق. أنت مسؤول عن المحتوى والروابط والأذونات التي تختارها وعن الامتثال للقوانين وشروط الخدمات الخارجية.

GitHub

يتطلب إنشاء المشروع ربط حساب GitHub ومنح الصلاحيات المطلوبة. تنشأ المشاريع في حساب GitHub الخاص بك، وتخضع لاستخدام GitHub وشروطه.

الاستخدام الممنوع

يُمنع استخدام Web2APK لإنشاء تطبيقات ضارة أو احتيالية أو لانتهاك حقوق الغير أو تجاوز ضوابط الأمان.

التوفر

قد تتأثر الخدمة بحدود Supabase أو GitHub Actions أو GitHub Pages أو الصيانة. لا نضمن توفر الخدمة دون انقطاع أو نجاح كل بناء لكل موقع.
