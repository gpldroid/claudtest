ما الذي نعالجه؟

يعالج Web2APK بيانات الحساب اللازمة للمصادقة، وبيانات المشاريع والبناء المرتبطة بحسابك، مثل اسم المشروع والرابط ومعرّف الحزمة وحالة البناء. عند استخدام GitHub، نستخدم رمز OAuth المؤقت لتنفيذ العمليات المطلوبة نيابةً عنك، ولا نحفظ الرمز في قاعدة البيانات.

لماذا نستخدم البيانات؟

لتسجيل الدخول، إنشاء مشاريع Android، تشغيل GitHub Actions، عرض حالة البناء، وتمكين تنزيل ملفات البناء الخاصة بك.

التخزين والأمان

تُخزن بيانات التطبيق التشغيلية في Supabase مع سياسات وصول على مستوى الصفوف. لا تُعرض مفاتيح الخدمة أو أسرار التوقيع في المتصفح. أسرار توقيع Android تُرسل إلى GitHub Secrets ولا تُحفظ في Web2APK.

المواقع الخارجية

قد يتعامل Web2APK مع GitHub وSupabase والموقع الذي تختاره لإنشاء التطبيق. تخضع هذه الخدمات لسياساتها الخاصة.

الاحتفاظ والحذف

نحتفظ ببيانات المشروع والبناء طالما كانت لازمة لتقديم الخدمة، ويمكنك طلب حذف بياناتك أو التوقف عن استخدام الخدمة.

English summary

Web2APK processes account, project, and build data to provide authentication and Android build services. GitHub OAuth access is used only for requested operations and provider tokens are not stored in the database. Row-level security protects user-owned data. External services remain subject to their own privacy policies.
